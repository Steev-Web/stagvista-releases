# StagVista Desktop v1.0.0

The first official release of **StagVista Desktop**, a live event timer and display application built to help event teams manage programs, schedules, and on-screen timing with ease.

### ✨ What's Included

- ⏱️ Live event countdown timer
- 📋 Program and event queue management
- ▶️ Previous, Next, and Skip controls
- 🖥️ External display support for projecting the timer
- 🔔 Automatic program time reminders
- 🕐 Current time display
- ✏️ Easy program editing
- 💾 Save and load event schedules
- 📄 CSV, and text-based schedule support ( JSON coming soon)
- 📺 Dedicated display view for audiences and production teams

### 🎯 Built For

StagVista is designed for churches, conferences, corporate events, concerts, ceremonies, and other live productions where accurate timing and program management matter.

### 🚀 v1.0.0

This release marks the first public version of StagVista Desktop and establishes the foundation for future features, integrations, remote control, and advanced live-production workflows.
